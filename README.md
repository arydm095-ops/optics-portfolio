# 作品集

张杨阳的作品集。包含光学设计、装调公差、光机结构和扫描跟踪分析。

- 成像镜组设计与公差：多波长精确追迹、像质评价、曲率优化、Monte Carlo 及装调补偿。
- [激光传输与热透镜分析](projects/laser-thermal/README.md)：有限体积热传导、三维温度剖切、热光 OPD、Gaussian 传播与补偿；15 项验证。
- 反射镜支撑光机 CAE：等效梁有限元、静力/模态/规定温差弯曲、谐波响应及厚度约束选型。
- 新项目的 [模型、验证和复现说明](projects/engineering/README.md)，入口 `projects/engineering/`。
- 光学与光机分析包含可旋转的三维镜组、多色光线、等效支撑变形与归一化振型展示。

- 三楔镜折射扫描：逐面折射追迹、参数调整、二维/三维可视化与数据导出。
- 四镜库德误差补偿：虚拟平台、多姿态扫描、调镜建议及补偿结果对比。
- 光电转台跟踪与视场协同：三维轴系姿态、自动跟踪、轨迹预测及相机视场协同。

入口为 index.html。库德调试控制台与虚拟平台须保留在同一目录，两者通过消息通信联动。三维绘图所需脚本已放在 demos/vendor 中。

全部计算与交互在浏览器内完成，访客无需安装程序。建议使用电脑体验。
