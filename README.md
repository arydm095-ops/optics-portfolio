# 光学仿真作品

在线交互式光学与光机仿真作品集，展示成像光学设计、装调公差、光机稳定性及扫描跟踪分析。

- 成像镜组设计与公差：多波长精确追迹、像质评价、曲率优化、Monte Carlo 及装调补偿。
- 反射镜支撑光机 CAE：等效梁有限元、静力/模态/规定温差弯曲、谐波响应及厚度约束选型。
- 新项目的 [模型、验证和复现说明](projects/engineering/README.md)，入口 `projects/engineering/`。

- 三楔镜折射扫描：逐面折射追迹、参数调整、二维/三维可视化与数据导出。
- 四镜库德误差补偿：虚拟平台、多姿态扫描、调镜建议及补偿结果对比。
- ARE 运动跟踪：三维轴系姿态、自动跟踪、轨迹预测及相机视场协同。

入口为 index.html。库德调试控制台与虚拟平台须保留在同一目录，两者通过消息通信联动。三维演示所需脚本已放在 demos/vendor 中。

全部计算与交互在浏览器内完成，访客无需安装程序。建议使用电脑体验。
