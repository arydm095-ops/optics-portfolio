# 光学设计与光机分析

镜组设计、公差和反射镜支撑分析。浏览器内完成计算，使用同一输入重复分析可复现结果，无服务器计算和商业软件运行依赖。

## 两个工程问题

1. **成像镜组设计与公差**：目标有效焦距 100 mm，入瞳 10 mm，半视场 3°，N-BK7 / N-SF5 胶合双片镜。建立精确光线追迹，评价多色点列、几何 MTF、纵向色差，优化处方，再比较制造偏差下的固定像面与调焦补偿。
2. **反射镜支撑的光机稳定性**：在端力、重力与规定截面温差下计算柔性支撑的位移、应力、固有频率和谐波响应，将端部转角传递为反射光束角偏差。对厚度进行约束选型。

入口：`index.html?project=optics` / `index.html?project=cae`。原作品集里的楔镜、库德及三轴跟踪作品保留。

三维视图使用同一组追迹交点、镜片处方与有限元结果，支持旋转/缩放。支撑静态位移及角度放大 200 倍，振型归一化为示意幅值；三维展示不会把一维等效梁变成三维实体求解。另附 [激光传输与热透镜分析](../laser-thermal/README.md)。

## 推荐操作顺序

1. 打开镜组设计，页面自动加载初始方案并调焦。通过“设计方案”切换初始方案、优化方案和当前调整方案。
2. 将像面 Z 增加 0.5 mm，点击计算，观察离焦如何改变点列和几何 MTF；再自动调焦。
3. 点击优化曲率与像面。优化前后都在各自最佳像面比较，采用相同的像质评价口径。
4. 点击“对当前方案进行公差分析”，自动对所选处方运行 120 个样本。将 RMS 阈值从 12 µm 改成 7 µm，结果会自动更新，观察合格率与统计区间；保持种子不变，比较不同公差或调焦范围。
5. 打开光机 CAE，先将温差置零，分辨机械变形和热弯曲；再恢复温差。
6. 扫描厚度；之后修改结构或载荷时，选型图与记录会自动更新。角偏差≤100″、一阶频率≥100 Hz、屈服安全系数≥2，筛选离散扫描中最轻可行方案。
7. 查看模型验证，导出 JSON、样本 CSV 和 HTML 报告。报告在浏览器打开后可打印为 PDF。

## 基准结果

以验证脚本保存的默认参数为准。优化使用每束 37 条光线评价目标函数，最终用每束 301 条光线复核，三视场和三波长总计 2709 条光线：

| 指标 | 初始方案（已调焦） | 优化后 |
|---|---:|---:|
| 多色多视场 RMS 半径 | 10.1014 µm | 5.9864 µm |
| 有效焦距 | 102.2087 mm | 100.0041 mm |

默认结构工况，3 mm 支撑厚度时光束角偏差 292.7626″、一阶频率 154.5894 Hz。厚度扫描选择 4.75 mm，总质量 45.65 g，角偏差 90.8127″、一阶频率 294.5667 Hz。仅在定义的等效梁、材料参数和载荷下成立，不是样机验收指标。

页面采用用户选定的光线数量，默认每束 121 条，与复核表的 301 条结果略有差别。完整参数、结果与时间戳见 `validation.json`。

## 光学模型

- 右手坐标，光沿 +z 传播。第一面顶点 z=0，球心在 z_vertex+R；R 正负代表曲率方向。
- 三个球面，前面空气→N-BK7，胶合面 N-BK7→N-SF5，后面 N-SF5→空气。厚度为轴向顶点距离，镜片边缘厚度须≥0.3 mm。
- 入射光瞳采样平面 z=−2 mm；Fibonacci 等面积圆盘采样，含中心点。物方无穷远，视场取 0、半视场和全视场，利用旋转对称性分析正半视场。
- 波长 486.1、587.6、656.3 nm 等权。Sellmeier 系数使用 SCHOTT N-BK7 / N-SF5 数据，公式中的波长单位为 µm。
- 光线与球面精确求交；矢量 Snell 折射计算方向，检查口径裁切和全反射。
- 光斑 RMS 为相对多色质心的二维径向均方根；综合 RMS 为三个视场 RMS 平方平均再开方。R80 是几何光线半径的 80% 分位数，不是衍射包围能量。
- 几何 MTF 为归一化点列分布的离散傅里叶模；T 在视场方向 x，S 在 y。它不等价于包含衍射的真实系统 MTF。
- 独立近轴 ABCD 矩阵采用光线向量 `[y, nθ]`，EFL=−1/C、BFL=−A/C，用作设计约束和追迹极限验证。
- 调焦：像面交点对 z 为线性函数，点列方差为二次函数；求极小值后按允许范围截断。
- 优化：有边界的 Nelder–Mead，设计变量 R1 / R2 / R3；目标为 `RMS² + 0.3 ((EFL−目标)/目标)² + 光线损失惩罚`。不使用目标结果倒推显示数据。

## 公差模型

11 个独立、均匀分布的误差变量：三个曲率相对误差、两个厚度误差、整组 X/Y 偏心、整组绕 Y 倾斜、两种玻璃的折射率偏差、像面位置误差。

镜组偏心/倾斜是刚体变换，不代表两个镜片各自的楔角或相对装调误差；胶合层尚未建模。折射率误差为各波长统一添加 Δn，未建模批次色散变化。

每个样本固定像面结果与调焦补偿结果使用同一组误差。补偿量限制在误差像面两侧的用户给定范围。合格率以全部样本为分母，不可行结构或光线通过率不足 90% 的样本计失败；中位值/P95只基于可计算样本。展示 Wilson 95% 合格率区间，120/120 不意味着真实生产合格率必然 100%。

敏感性采用单参数 ± 端点，显示最差端点相对标称 RMS 的变化。CSV 导出的是实际误差幅值，JSON 保留归一化误差及公差上限。

## 光机有限元模型

二维平面内 Euler–Bernoulli 梁，每节点两个自由度 `[w, θ]`，根部位移与转角固定。四自由度 Hermite 单元组装 K 和一致质量 M。内部全部使用 SI；界面尺寸为 mm、角误差为角秒。

`EI=E b h³/12`，施加端力和镜片重力，梁自重为均布载荷。镜片端部平动质量与直径对应的转动惯量加入质量矩阵。

规定的线性截面温差产生自由热曲率 `κ_T=α ΔT/h`。使用等效节点热弯矩加载；应力计算为 `E h/2 (κ−κ_T)`，避免把自由热弯曲错误算成机械应力。

静力解 Ku=F；模态解 Kφ=λMφ。质量矩阵 Cholesky 变换后，循环 Jacobi 求解对称特征值，振型质量归一化。谐波响应采用前 12 阶模态叠加及恒定模态阻尼。

端部平面内转角 φ 映射为反射光束角变化约 2φ；传播 L_d 后的光斑角度分量位移为 L_d tan(2φ)。镜面平移引起的光束位置变化没有混入这一数值。

**边界**：不是三维实体有限元；不含扭转、夹紧接触、镜面面形、预紧、塑性、真实热传导、随机振动。长厚比<10需剪切梁/三维复核，材料为代表值。大转角与极小阻尼共振也应另行复核。

## 数值验证与本地运行

无 npm 安装步骤。任意静态服务器均可运行；不要用 file:// 直接打开，因为 Worker 和 JSON 读取需要 HTTP。

```sh
# 在仓库根目录
python -m http.server 8000
# 浏览器访问 http://localhost:8000/projects/engineering/
node projects/engineering/tests.cjs
```

测试通过后重新生成 `validation.json`。32 项检查覆盖材料折射率、Snell、全反射、可逆性、近轴极限、光路对称性、优化独立复核、MTF 归一化、公差复现、逐样本补偿、悬臂静力/热弯曲解析解、力平衡、纯梁前三阶模态解析解与网格收敛、离散选型约束。

纯端力悬臂解析解：`w_tip=F L³/(3EI)`、`θ_tip=F L²/(2EI)`。纯热弯曲：`w_tip=κ_T L²/2`、`θ_tip=κ_T L`。纯梁固有频率：`f_n=β_n²/(2π) sqrt(EI/(ρA L⁴))`，β 前三阶为 1.875104、4.694091、7.854757。
